Switching tools or starting a new coding session often means explaining the same decisions all over again.

THE APPROACH

Keep shared memory locally, retrieve it with full-text search, and turn saved decisions into workspace rules.

THE RESULT

A reusable context layer with structured handoffs, secret redaction, and a local memory dashboard.
